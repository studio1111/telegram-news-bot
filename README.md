# Telegram News Bot

ربات جمع‌آوری، پردازش و انتشار خودکار خبر برای کانال تلگرام.

## معماری
RSS/Atom → جمع‌آوری → حذف تکراری → Gemini → ترجمه/خلاصه/دسته‌بندی → فیلتر تکنولوژی → Telegram

GitHub Actions هر ۳۰ دقیقه (دقیقه‌های ۷ و ۳۷) اجرا می‌شود و خبرهای ۹۰ دقیقه اخیر را بررسی می‌کند. پنجره عمداً بزرگ‌تر از فاصله اجراست چون cron گیت‌هاب گاهی دیر اجرا می‌شود یا یک اجرا را جا می‌اندازد؛ خبرهای منتشرشده، تکراری و غیرتکنولوژی در data/state.json ثبت می‌شوند تا دوباره پردازش یا منتشر نشوند. طول پنجره با متغیر محیطی `NEWS_WINDOW_MINUTES` قابل تغییر است.

## تضمین‌های انتشار
- وضعیت بعد از هر انتشار موفق ذخیره می‌شود، پس کرش یا توقف وسط اجرا باعث انتشار تکراری نمی‌شود.
- اجرای در حال انتشار هرگز توسط اجرای بعدی کنسل نمی‌شود.
- اگر `sendRichMessage` رد شود، پیام به صورت متن ساده ارسال می‌شود؛ در timeout شبکه این کار انجام نمی‌شود تا پیام دوبار ارسال نشود.
- خبرها از قدیمی به جدید منتشر می‌شوند.

## Secrets
در Settings → Secrets and variables → Actions این سه Secret را اضافه کنید:
- GEMINI_API_KEY
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

## اجرا
```bash
pip install -r requirements.txt pytest
pytest -q
python -m app.main
```

منابع RSS در data/sources.json قابل تغییر هستند.
